# Pears Construction CRM

A lead and pipeline CRM for Pears Construction.

- Dashboard: marketing leads analysis with conversion rate and lead sources
- Leads: searchable table with filters
- Pipeline: drag-and-drop board (New, Try to reach, Contacted, Qualified, Proposal, Negotiation, Won, Lost, Not qualified, On hold)
- Analytics: forecast, win rate, funnel, sources, project types

Open `index.html` in a browser to view it.

Note: this version was built inside Claude and stores leads in Claude's own database. Outside Claude it runs without saving. To save leads, connect it to a backend such as PHP and MySQL.
